Add a news fragment here for each user-facing change in a pull request.

Fragment names follow `{issue}.{type}.md`, for example `42.feature.md`.

For changes without an issue or PR number yet, use an orphan fragment with a leading `+`, for example `+short-description.misc.md`. Towncrier still includes these when building the changelog.

Valid types: `feature`, `bugfix`, `doc`, `misc`

Dependabot PRs receive a `misc` fragment automatically via CI.
